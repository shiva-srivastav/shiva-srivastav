### 👨‍💻 About Me

I'm a Software Developer focused on building scalable, production-ready applications using **Java, Spring Boot, Python, FastAPI, PostgreSQL, Redis** and modern cloud technologies.

Currently, I'm leading engineering initiatives for **Digveda**, an all-in-one spirituality platform that I've been building from scratch. My work spans backend architecture, system design, REST APIs, payment systems, AI-powered features, third-party integrations, logistics, real-time communication, performance optimization and production deployments.

At Digveda, I've worked on AI-powered Palmistry, Numerology, Kundli generation, quizzes, e-commerce and order workflows, online consultations, WhatsApp communication, logistics and payment infrastructure.

### 🛠️ What I Work On

- **Backend & System Design**: Java, Spring Boot, Python, FastAPI, Vert.x, REST APIs, Microservices, LLD & HLD
- **Databases & Performance**: PostgreSQL, MySQL, MongoDB, Redis, query optimization and caching
- **Payments & Integrations**: Razorpay, webhooks, payment reconciliation, WATI, NimbusPost, Agora and third-party APIs
- **AI/ML**: Python, NLP, TensorFlow, MCP servers and AI-powered product features
- **DevOps & Cloud**: Docker, AWS, Linux, CDN, Git and production deployments
- **Web Performance**: Core Web Vitals, API performance, scalability and technical SEO

I enjoy taking products from an idea to a working production system: designing the architecture, building the backend, integrating external services, solving production problems, and continuously improving performance and reliability.

🌱 Always learning more about **distributed systems, backend engineering, AI and cloud-native development**.
